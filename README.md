# NDA SSB Personal Interview — Interactive Practice Quiz

## Run
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser. No server or installation is required.

## Features
- All 100 source questions, in the original four sets.
- Written response area for each question.
- Hidden thinking cues and expandable source sample answers.
- Previous/next navigation and optional randomized question order.
- Self-assessment: Ready / Needs practice.
- Progress indicators and local browser storage.
- JSON performance report download and printable practice completion record.
- Responsive layout and keyboard-accessible controls.

## Important scoring note
SSB interview responses are personal and open-ended. The application does not pretend that a sample answer is the only correct response. The readiness percentage is calculated from the learner's own Ready / Needs practice ratings. It is not an official SSB score or a prediction of selection.

## Source handling
Questions and sample answers are taken from the supplied `NDA SSB Personal Interview - 100 Questions with Sample Answers.md`. Advice and interface flow follow `Interactive Quiz ver 2.md`. Personal placeholders in sample answers (such as `[Your Name]`) are retained for the learner to adapt.
